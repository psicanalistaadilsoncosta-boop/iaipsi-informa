Achei o problema. Está na page.tsx, linha 42:

ts
async function fetchAndParseFeed(url: string) {
  const response = await fetch(url, {
    headers: { ... },
    // ← SEM timeout!
  });

25 feeds RSS sendo buscados em paralelo, sem nenhum timeout. Se qualquer feed demorar ou travar — e o Google News, Globo e BBC às vezes ficam lentos — a página inteira fica esperando para sempre.

A correção é adicionar signal: AbortSignal.timeout(8000) no fetch do feed, e também no getOfertasMix da Lomadee (linhas 375–382) que também não tem timeout.

Procure por:

ts
  const response = await fetch(url, {
    headers: {
      'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/153.0.0.0 Safari/537.36',
      'Accept': 'application/rss+xml, application/xml, text/xml, */*;q=0.8',
      'Accept-Language': 'pt-BR,pt;q=0.9,en;q=0.8',
    },
  });

Troque por:

ts
  const response = await fetch(url, {
    headers: {
      'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/153.0.0.0 Safari/537.36',
      'Accept': 'application/rss+xml, application/xml, text/xml, */*;q=0.8',
      'Accept-Language': 'pt-BR,pt;q=0.9,en;q=0.8',
    },
    signal: AbortSignal.timeout(8000),
  });

E para a Lomadee, procure por:

ts
    const [campData, brandData] = await Promise.all([
      fetch(`${BASE_URL}/affiliate/campaigns?limit=20`, {
        headers: { 'x-api-key': API_KEY },
        next: { revalidate: 900 },
      }).then(r => r.json()),
      fetch(`${BASE_URL}/affiliate/brands?limit=20`, {
        headers: { 'x-api-key': API_KEY },
        next: { revalidate: 900 },
      }).then(r => r.json()),
    ]);

Troque por:

ts
    const [campData, brandData] = await Promise.all([
      fetch(`${BASE_URL}/affiliate/campaigns?limit=20`, {
        headers: { 'x-api-key': API_KEY },
        next: { revalidate: 900 },
        signal: AbortSignal.timeout(8000),
      }).then(r => r.json()),
      fetch(`${BASE_URL}/affiliate/brands?limit=20`, {
        headers: { 'x-api-key': API_KEY },
        next: { revalidate: 900 },
        signal: AbortSignal.timeout(8000),
      }).then(r => r.json()),
    ]);

Faça as duas trocas, salve e reinicie o servidor. Se um feed travar, vai cair no catch depois de 8 segundos e a home carrega normalmente sem ele.
